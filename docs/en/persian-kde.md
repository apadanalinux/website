# KDE Plasma & Persian Localization

Apadana Linux provides an enterprise-tuned **KDE Plasma 6** environment featuring deep Persian localization out-of-the-box.

## Factory Localization Features

1. **Standard Right-to-Left (RTL) Layout**: Polished RTL symmetry for all system dialogs, panels, taskbars, and notification centers.
2. **Vazirmatn Typography**: Integrated high-legibility Persian fonts with crisp rendering across all screen resolutions.
3. **Solar Jalali Calendar**: Native integration in the desktop taskbar clock, calendar widgets, and system date formatting.
4. **Standard Persian Keyboard ISIRI 9147**: Full support for zero-width non-joiner (`Shift + Space`) and Persian typographical punctuation.
