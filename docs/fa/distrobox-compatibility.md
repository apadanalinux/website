# توسعه و ابزارهای اختصاصی با Distrobox

آپادانا به صورت پیش‌فرض شامل ابزار قدرتمند **Distrobox** است. Distrobox به توسعه‌دهندگان، تحلیل‌گران داده و مهندسان IT امکان می‌دهد بدون کوچک‌ترین تغییری در فایل‌سیستم ریشه آپادانا، هر توزیع دلخواه لینوکس را در کانتینری شفاف اجرا کنند.

## سناریوهای کاربردی سازمانی

- اجرای ابزارهای قدیمی شرکت که صرفاً روی یک نسخه خاص از Ubuntu یا Debian کامپایل شده‌اند.
- محیط توسعه ایزوله برای برنامه‌نویسان با ابزارهای Node.js، Python، Go و Rust بدون آلوده‌سازی سیستم ریشه.

```bash
# ایجاد یک محیط اوبونتو برای ابزارهای خاص
distrobox create --name dev-box --image ubuntu:24.04

# ورود به محیط کانتینر
distrobox enter dev-box

# خروجی گرفتن از یک برنامه خط‌فرمان به منوی دسکتاپ میزبان
distrobox-export --app myapp
```
