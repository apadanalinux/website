# اپلیکیشن‌های اندروید با Waydroid

بسیاری از سازمان‌ها و نهادهای خدماتی دارای اپلیکیشن‌های اختصاصی سازمانی (نظیر همراه بانک‌های سازمانی، سامانه‌های امضای دیجیتال و اتوماسیون اداری) هستند که نسخه لینوکسی ندارند.

آپادانا با ادغام **Waydroid**، کانتینر اندروید مبتنی بر لایه‌های LXC را به صورت مستقیم و بدون شبیه‌سازی سنگین (Emulation) بر بستر Wayland اجرا می‌کند.

## ویژگی‌ها:
- شتاب‌دهی سخت‌افزاری گرافیکی مستقیم GPU
- اشتراک‌گذاری حافظه کلیپ‌بورد بین لینوکس و برنامه‌های اندرویدی
- نمایش مستقیم پنجره‌های اپلیکیشن اندروید در تسک‌بار KDE Plasma

```bash
# راه‌اندازی اولیه محیط Waydroid
sudo waydroid init

# اجرای نشست Waydroid
waydroid session start
```
