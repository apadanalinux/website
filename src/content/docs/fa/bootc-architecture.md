# معماری bootc در آپادانا لینوکس

فناوری **bootc** (Bootable OCI Containers) رویکردی استاندارد است که در آن تمام محتوای سیستم‌عامل دسکتاپ دقیقاً مشابه یک ایمیج کانتینر استاندارد کانتینرد (Container Registry) بیلد و مدیریت می‌شود.

```text
┌────────────────────────────────────────────────────────┐
│           Enterprise Desktop Layer (KDE Plasma)        │
├────────────────────────────────────────────────────────┤
│ Application Runtimes (Flatpak / Distrobox / Waydroid) │
├────────────────────────────────────────────────────────┤
│           Immutable Read-Only Root (/usr, /lib)        │
├────────────────────────────────────────────────────────┤
│          OSTree / bootc Transactional Deployments      │
├────────────────────────────────────────────────────────┤
│               Linux Kernel & Base Hardware             │
└────────────────────────────────────────────────────────┘
```

## نحوه عملکرد لایه فقط-خواندنی

در آپادانا، دایرکتوری‌های حساس نظیر `/usr` و `/bin` به صورت `ro` (Read-Only) مونت می‌شوند:

- فایل‌های پیکربندی در `/etc` قرار دارند و تغییرات مدیریتی با استفاده از ۳-way merge هنگام آپدیت هوشمندانه حفظ می‌شوند.
- داده‌های کاربران در `/home` و متغیرهای سرویسی در `/var` نگهداری می‌شوند و هرگز در هنگام تعویض یا آپدیت سیستم‌عامل پاک نمی‌شوند.

## دستورات اساسی بررسی وضعیت bootc

برای مشاهده وضعیت تصویر کنونی سیستم و تاریخچه استقرارها:

```bash
# مشاهده وضعیت ایمیج فعال و صف استقرار
sudo bootc status

# بررسی وجود به‌روزرسانی در رجیستری سازمان
sudo bootc upgrade --check

# اعمال به‌روزرسانی جدید
sudo bootc upgrade
```
